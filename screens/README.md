## 資料模型約定（已確認）

- **老師**：課程層級人工指派（主授＋代課）；系統驗證「每週可授課時間」與全中心課表衝突。
- **教室**：課程只儲存「需求」（容納人數、設備、偏好分校）；**實際教室由智慧排課逐堂指派**，單堂例外（維修等）自動改派並記錄。
- **智慧排課四大功能**：週期展開成逐堂、全中心衝突偵測（師/室/學員/可授時段）、逐堂教室指派、例外處理（代課、換教室、調課、加課、取消）。
